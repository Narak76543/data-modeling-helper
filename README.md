# Data Modeling Helper

A tool to help teams — especially junior developers and students — build correct, validated data models before handing them off to backend developers. Thesis project, 10-month timeline, 3-person team.

## Repo structure

```
data-modeling-helper/
├── AGENTS.md           # Context file read by AI coding agents (Antigravity, Gemini CLI, etc.)
├── README.md           # This file
└── docs/
    ├── BRD.md           # Business Requirements Document
    ├── requirements.md  # Functional & non-functional requirements
    ├── roadmap.md        # 10-month phased roadmap
    └── tech-stack.md      # Architecture & tech stack decisions (fill in once decided)
```

## Status

Phase 1 — Preparation (Month 1–2). See `docs/roadmap.md`.

## Getting started (for AI agents)

If you are an AI coding agent (Antigravity, Gemini CLI, Claude Code, etc.), read `AGENTS.md` first, then `docs/BRD.md` and `docs/requirements.md` before proposing a plan or writing code.

## Getting started (for team members)

1. Read `docs/BRD.md` for the full problem statement and scope.
2. Read `docs/roadmap.md` for what phase we're in and what's due.
3. Fill in `docs/tech-stack.md` once the stack is decided as a team.
4. Fill in the team section of `AGENTS.md` with roles.
